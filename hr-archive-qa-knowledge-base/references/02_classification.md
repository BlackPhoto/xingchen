# 档案内容与分类

## 十大类总览

| 类别 | 名称 | 主要内容 |
|------|------|---------|
| 一类 | 履历类 | 干部履历表、干部简历等 |
| 二类 | 自传和思想类 | 自传、党性分析、思想汇报等 |
| 三类 | 考核鉴定类 | 年度考核、挂职鉴定、工作表现等 |
| 四类 | 学历学位等 | 学历学位(4-1)、职称(4-2)、学术(4-3)、培训(4-4) |
| 五类 | 政审审计审核类 | 政审、审计、审核认定、廉洁评价等 |
| 六类 | 党团类 | 入党志愿书、入团志愿书、党员登记等 |
| 七类 | 表彰奖励类 | 嘉奖、记功、荣誉称号等 |
| 八类 | 违规违纪违法处理处分类 | 党纪政务处分、刑事判决、失信记录等 |
| 九类 | 工资任免出国会议代表类 | 工资(9-1)、任免(9-2)、出国(9-3)、会议代表(9-4) |
| 十类 | 其他 | 报到证、体检表、调动介绍信等 |

（条例第十九条）

## 第一类：履历类材料

主要有《干部履历表》和干部简历等材料。具体包括：
- 干部履历表
- 干部简历
- 学生学籍卡片和登记表
- 工作人员登记表
- 干部任免呈报表
- 录（聘）用审批表
- 公务员登记表
- 参照公务员法管理机关（单位）工作人员登记表
- 干部简要情况登记表
- 其他各种履历表和简历材料

## 第二类：自传和思想类材料

主要有自传、参加党的重大教育活动情况和重要党性分析、重要思想汇报等材料。具体包括：
- 自传
- 个人自述材料
- 思想汇报材料

## 第三类：考核鉴定类材料

主要有平时考核、年度考核、专项考核、任（聘）期考核，工作鉴定，重大政治事件、突发事件和重大任务中的表现，援派、挂职锻炼考核鉴定，党组织书记抓基层党建评价意见等材料。具体包括：
- 年度考核登记表
- 平时考核材料
- 专项考核材料
- 任期考核材料
- 援派、挂职锻炼鉴定材料
- 工作鉴定材料
- 重大政治事件、突发事件中的表现材料
- 党组织书记抓基层党建评价意见

## 第四类：学历学位、专业技术职务（职称）、学术评鉴和教育培训类材料

下设四个子类：
- **4-1 学历学位类**：中学以来取得的学历学位
- **4-2 专业技术职务（职称）类**：职业（任职）资格和评聘专业技术职务（职称）
- **4-3 学术评鉴类**：当选院士、入选重大人才工程，发明创造、科研成果获奖、著作译著和有重大影响的论文目录
- **4-4 教育培训类**：政策理论、业务知识、文化素养培训和技能训练情况

## 第五类：政审、审计和审核类材料

主要有：政治历史情况审查，领导干部经济责任审计和自然资源资产离任审计的审计结果及整改情况、履行干部选拔任用工作职责离任检查结果及说明，证明，干部基本信息审核认定、干部人事档案任前审核登记表，廉洁从业结论性评价等材料。

**专项审核表和审核认定表也归入此类。**

## 第六类：党、团类材料

主要有《中国共产党入党志愿书》、入党申请书、转正申请书、培养教育考察，党员登记表，停止党籍、恢复党籍，退党、脱党，保留组织关系、恢复组织生活，《中国共产主义青年团入团志愿书》、入团申请书，加入或者退出民主党派等材料。具体包括：
- 入党志愿书及入党申请书
- 转正申请书
- 入党积极分子培养教育考察材料
- 入团志愿书及入团申请书
- 党员登记表（含1985年、1990年党员登记）
- 停止党籍、恢复党籍材料
- 退党、脱党材料
- 加入或退出民主党派材料

## 第七类：表彰奖励类材料

主要有表彰和嘉奖、记功、授予荣誉称号，先进事迹以及撤销奖励等材料。具体包括：
- 嘉奖审批表
- 记功审批表
- 授予荣誉称号审批表
- 先进事迹材料
- 各种荣誉称号证书
- 撤销奖励材料

## 第八类：违规违纪违法处理处分类材料

主要有：党纪政务处分，组织处理，法院刑事判决书、裁定书，公安机关有关行政处理决定，有关行业监管部门对干部有失诚信、违反法律和行政法规等行为形成的记录，人民法院认定的被执行人失信信息等材料。

**此类材料对干部使用有重要影响。**

## 第九类：工资、任免、出国和会议代表类材料

下设四个子类：
- **9-1 工资待遇类**：工资待遇审批、参加社会保险
- **9-2 任免类**：录用、聘用、招用、入伍、考察、任免、调配、军队转业（复员）安置、退（离）休、辞职、辞退，公务员登记、遴选、选调、调任、职级晋升，职务职级套改，事业单位管理岗位职员等级晋升
- **9-3 出国（境）类**：出国（境）审批
- **9-4 会议代表类**：当选党的代表大会、人民代表大会、政协会议、群团组织代表会议、民主党派代表会议等代表（委员）及相关职务

## 第十类：其他可供组织参考的材料

主要有毕业生就业报到证、派遣证，工作调动介绍信，国（境）外永久居留资格、长期居留许可等证件有关内容的复印件和体检表等材料。具体包括：
- 体检表
- 毕业生就业报到证、派遣证
- 工作调动介绍信
- 国（境）外永久居留资格复印件
- 婚姻状况材料
- 户口迁移材料
- 其他可供组织参考的材料
