# 纪律和监督

## 十一项禁止性纪律

（一）严禁篡改、伪造干部人事档案
（二）严禁提供虚假材料、不如实填报档案信息
（三）严禁转递、接收、归档涉嫌造假或者来历不明的档案材料
（四）严禁利用职务便利实施档案造假，授意、指使、纵容、默许他人档案造假，为档案造假提供方便
（五）严禁插手、干扰有关部门调查、处理档案造假问题
（六）严禁擅自抽取、撤换、添加档案材料
（七）严禁圈划、损坏、扣留、出卖、交换、转让、赠送档案
（八）严禁擅自提供、摘录、复制、拍摄、保存、丢弃、销毁档案
（九）严禁违规转递、接收和查（借）阅档案
（十）严禁擅自将档案带出国（境）外
（十一）严禁泄露或者擅自对外公开档案内容
（条例第三十九条）

## 违纪追责

依据有关规定予以纠正；根据情节轻重，给予批评教育、组织处理或者党纪政务处分，并视情追究相关人员责任。涉嫌违法犯罪的，按照国家法律法规处理。（条例第四十二条）

## 监督检查

（1）党委（党组）及其组织人事部门对档案工作和条例实施情况进行监督检查
（2）纪检监察机关、巡视巡察机构按照有关规定进行监督检查

下级机关和党员、干部、群众对档案工作中的违纪违规行为，有权向上级党委（党组）及其组织人事部门、纪检监察机关举报、申诉。（条例第四十条、第四十一条）

# 专项审核实务

## 审核项目

根据2020新版专项审核表，主要审核以下项目：

| 审核项目 | 审核内容 |
|---------|---------|
| 出生时间 | 记载是否一致、最早/最新材料记载、身份证号码、真实性存疑（涂改/材料存疑）、组织认定情况 |
| 参加工作时间 | 材料齐全规范、记载是否一致、真实性存疑、组织认定情况 |
| 入党时间 | 材料齐全规范、是否补填《入党志愿书》、记载是否一致、真实性存疑、组织认定情况 |
| 学历学位 | 材料齐全规范、记载是否一致（全日制/在职）、是否把培训填为学历/低学历填高学历/在职填全日制/无学位填有学位、真实性存疑、组织认定 |
| 工作经历 | 材料齐全规范（履历/任免）、破格提拔及材料、记载是否一致、真实性存疑 |
| 奖惩情况 | 材料齐全规范、填写真实准确 |
| 家庭主要成员及重要社会关系 | 应填人员齐全、信息准确 |

## 出生时间审核要点

1. 核对各材料记载是否一致
2. 找出最早形成材料和最新材料记载的出生时间
3. 核对身份证号码
4. 检查是否存在涂改或材料存疑等真实性存疑情况
5. 记录组织认定情况

**出生日期认定一般以最早形成的档案材料记载为准。**

## 学历学位审核常见问题

1. 把培训填为学历
2. 低学历填高学历
3. 在职填全日制
4. 无学位填有学位

审核时需区分全日制教育和在职教育，分别核对毕业院校、系及专业。

## 工作经历审核要点

1. 材料是否齐全规范（履历材料、任免材料）
2. 是否存在破格提拔情况及相应材料是否齐全
3. 各材料记载的工作经历是否一致
4. 是否存在真实性存疑问题

## 专项审核认定表填写要求

1. "审核意见"栏填写主要问题及意见，涂改需逐份登记
2. "组织人事部门意见"栏填写组织认定意见，分管领导签字+公章
3. "本人意见"栏，同意则填写"同意"并签字
4. "备注"栏填写：本人拒不签字情况；涉嫌造假难以查清需记录在案的情况
5. 内容较多可另附页并加盖公章
6. 一式两份：一份归入档案第五类，一份由组织人事部门集中保管

## 专项审核表基本信息表包含内容

姓名、性别、出生年月、照片、民族、籍贯、出生地、入党时间、参加工作时间、健康状况、专业技术职务（职称）、熟悉专业有何专长、学历学位（全日制教育/在职教育 + 毕业院校系及专业）、现任职务、简历、奖惩情况、年度考核结果、家庭主要成员及重要社会关系

# 任前审核与档案转递

## 任前审核情况登记表

在干部提拔任用前，对其人事档案进行全面审核，审核发现的问题及处理情况予以登记，作为干部任用的重要依据。审核不合格的，一律暂缓任用程序。

填表说明主要内容：
1. 审核工作由2名以上党员干部承担，分为初审和复审
2. 审核中发现的有关问题应当逐项登记
3. 每类材料审核完毕后填写审核意见
4. 对审核发现的问题，要逐一记载相关材料名称及形成时间
5. 审核完成后，初审人、复审人均应签字
6. 涉及信息重新认定的，应按认定意见填写

## 档案副本申请

副处级或者相当职务以上干部，根据工作需要可以建立人事档案副本。需填写《建立领导人员人事档案副本的申请表》，经审批后建立。副本由正本主要材料的复制件构成，正本变更时副本应相应变更。
