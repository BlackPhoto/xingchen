## 二、【空间布局】（基于逻辑关系动态生成，不再强制矩形网格）

### 2.1 逻辑关系识别

- 首先明确本页必须传达的**核心逻辑关系**（单选或组合）。
- 常见关系有：
  - **并列列表**：无时间顺序的多项要点
  - **连续流程**：线性步骤、时间线、阶段推进
  - **循环闭环**：首尾衔接、持续迭代
  - **层次嵌套**：树形结构、组织架构、包含关系
  - **中心辐射**：一个核心与多个外围要素的关系
  - **矩阵对比**：两个维度交叉比较（2×2、3×3等）
  - **棱锥递进**：金字塔型层级增长或集中
  - **自由语义组合**：如「左侧流程+右侧详情」「上方金字塔+下方数据卡片」

### 2.2 布局模式选择

- 从下列模式库中选择最匹配的**布局框架**（可混合使用）：
  1. **横向流程**：主容器 flex row，各节点等距排列，节点间用箭头/连接线串接。
  2. **纵向时间线**：主容器 relative，左侧（或居中）竖线+右侧（或交错）内容卡片。
  3. **环形循环**：主容器 relative，各节点绝对定位在圆形/椭圆形路径上，中央放置核心元素或总述文字；连接线可为弧形箭头。
  4. **树形层次**：主容器 relative，用直线/折线连接父子节点，可配合 CSS Grid 或 Flex 辅助子节点排列。
  5. **中心辐射**：主容器 relative，中心节点固定于画面几何中心，外围节点均匀分布在以中心为圆心的圆/椭圆上。
  6. **矩阵网格**：CSS Grid 2×2 / 3×3 / 3×4，每格内放置卡片。
  7. **金字塔/棱锥**：主容器 relative，各层级水平居中堆叠，宽度由窄到宽或由宽到窄。
  8. **自由分区**：基于语义组合上述模式（如左侧树形导航+右侧详情卡片）。

### 2.3 关键锚点与坐标（仅给出核心几何参数，废除ASCII示意图）

- 对于**规则网格布局**（矩阵、并列卡片），用 `x, y, width, height` 或 `flex/grid` 参数说明，但不再要求画出ASCII方框。
- 对于**不规则布局**，给出一个「布局计算参数表」，例如：

```
布局类型：中心辐射（6个节点均匀分布）
中心点 C：(640, 384)
分布半径 R：260px
起始角度：-90°（即正上方）
节点尺寸：120×120px（圆角方形卡片）
各节点中心坐标计算：
  节点1：x = 640 + 260×cos(-90°)=640, y = 384 + 260×sin(-90°)=124
  节点2：x = 640 + 260×cos(-30°)=865, y = 384 + 260×sin(-30°)=254
  ...（以此类推，按角度间隔60°计算）
连接线：从节点中心指向中心点，颜色 #e2e8f0, stroke-width:2，止于节点边缘；可添加箭头指向中心（表示汇聚）
中心图形：一个圆环（内径80px，外径120px，stroke #1e5bb5, stroke-width:4），内部放置核心标题文字
```

### 2.4 灵活实现规则

- 所有元素最终必须固定在 **1280×768px 画布内**，使用 `position: absolute` 或精确 Flex/Grid 控制，允许微量微调（±4px），但**相对几何关系必须严格**。
- 连接线、箭头、不规则形状一律使用**内联SVG**绘制。
- 允许生成模型根据文字长度适度扩大节点尺寸（上限不超过原尺寸的120%），但必须保持对称或整体重心不偏移。
- 如果使用 Flex/Grid，确保最外层容器 `width:1280px; height:768px; overflow:hidden;`，避免内容溢出。

# 输出原则

1. **精确优于模糊**：每个元素都要有坐标/尺寸/色值，禁止出现"大概在中间"、"适当大小"等模糊描述。
2. **完备优于简洁**：宁可冗余也不遗漏，下游AI无法脑补你没写的东西。
3. **结构化优于散文**：使用表格、列表、键值对，不要写段落式描述。
4. **视觉优先级排序**：先描述最大/最醒目的元素，再到细节装饰。
5. **中文内容精确引用**：所有需要显示的文字必须原样给出，包括标点符号。
6. **相对关系明确**：元素之间的关系用"在X的下方20px"/"与Y左对齐"等方式明确表达。
7. **逻辑驱动布局**：先识别关系，再选模式，最后给参数；严禁所有页面都用ASCII矩形框描述。
8. **色彩严格遵守**：所有色值必须来自第六节【颜色系统】中映射的主题字段，不得自行发明新色值。

### 图标绘制原则

```
1. 统一视觉风格：同一页面内所有图标必须保持一致的风格(线性/面型)和描边粗细
2. 统一尺寸：同级别图标使用相同的viewBox和显示尺寸
3. 像素对齐：坐标尽量使用整数值，避免半像素模糊
4. 简化优先：PPT图标追求可识别性，不追求细节，通常3-5个SVG元素即可
5. 底座统一：如果图标需要底座圆/底座方块，同一页面保持一致的底座尺寸和样式
```
