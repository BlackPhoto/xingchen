# 幻灯片页面类型

将**每一页幻灯片**准确归类为以下 5 种类型之一：

## 1. 封面页

- **适用**：开场 + 定调
- **内容**：大标题、副标题/演讲者、日期/场合、强背景或主题图形

### 版式选项

**非对称左右版式**
- 文本集中在一侧，图片放在另一侧
- 适合：企业演示、产品发布、专业报告
```
|  标题与副标题    |    视觉/图片      |
|  描述            |                   |
```

**居中对齐版式**
- 内容居中，配合背景图片
- 适合：启发式演讲、活动演示、创意提案
```
|                                        |
|              [背景图片]                |
|                主标题                  |
|                副标题                  |
|                                        |
```

### 字号层级

| 元素 | 推荐尺寸 | 相对基准比例 |
|---------|-----------------|---------------|
| 主标题 | 72-120px | 3x-5x |
| 副标题 | 28-40px | 1.5x-2x |
| 辅助文本 | 18-24px | 1x（基准） |
| 元信息（日期、姓名） | 14-18px | 0.7x-1x |

**关键原则：**
1. **强烈对比**：主标题至少应比副标题大 2-3 倍
2. **视觉锚点**：最大文字成为视觉焦点
3. **层级可读**：观众应立即理解最重要的信息
4. **避免相近**：相邻文本元素的字号差异不要小于 20%

### 内容元素

1. **主标题**：必需，字号最大
2. **副标题**：需要补充上下文时使用，必须明显小于标题
3. **图标**：能强化主题时使用
4. **日期/活动信息**：相关时使用，字号最小
5. **公司/品牌 Logo**：代表组织时使用
6. **演讲者姓名**：用于主题演讲，小而克制

### 设计决策

考虑：用途（企业/教育/创意）、受众、语气、内容量、所需视觉素材。

### 工作流

1. **分析**：理解主题、受众和目的
2. **选择版式**：根据内容选择
3. **编写页面**：使用 PptxGenJS。使用形状和 SVG 元素增加视觉趣味
4. **验证**：生成 `slide-XX-preview.pptx` 预览。用 `python -m markitdown slide-XX-preview.pptx` 提取文本，确认内容完整且没有占位文本残留

## 2. 目录页

- **适用**：导航 + 设定预期（3-5 个章节）
- **内容**：章节列表（可选图标 / 页码）

### 版式选项

**编号纵向列表**：适合 3-5 个章节、直线型演示
```
|  目录                          |
|                                |
|  01  章节标题一                |
|  02  章节标题二                |
|  03  章节标题三                |
```

**双栏网格**：适合 4-6 个章节、内容较丰富的演示
```
|  目录                            |
|                                  |
|  01  章节一      02  章节二      |
|      描述            描述        |
|  03  章节三      04  章节四      |
```

**侧栏导航**：适合 3-5 个章节、现代/企业风
```
| ▌01 |  章节标题一                 |
| ▌02 |  章节标题二                 |
| ▌03 |  章节标题三                 |
```

**卡片式**：适合 3-4 个章节、创意/现代风
```
|  目录                                  |
|  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  |
|  │ 01  │  │ 02  │  │ 03  │  │ 04  │  |
|  │标题 │  │标题 │  │标题 │  │标题 │  |
|  └─────┘  └─────┘  └─────┘  └─────┘  |
```

### 字号层级

| 元素 | 推荐尺寸 | 相对基准比例 |
|---------|-----------------|---------------|
| 页面标题（“目录” / “议程”） | 36-44px | 2.5x-3x |
| 章节编号 | 28-36px | 2x-2.5x |
| 章节标题 | 20-28px | 1.5x-2x |
| 章节描述 | 14-16px | 1x（基准） |

**关键原则：**
1. **编号清晰**：章节编号要视觉突出，可用加粗、强调色或更大字号
2. **便于扫读**：观众应能在 2-3 秒内扫完所有章节
3. **间距一致**：章节之间垂直间距一致
4. **视觉标记**：用彩色点、线条、编号或图标锚定每一节
5. **避免拥挤**：描述最多一行，也可以省略

### 内容元素

1. **页面标题**：必需，例如“目录”“议程”“概览”
2. **章节编号**：格式一致，如 01、02... 或 I、II...
3. **章节标题**：清楚、简洁
4. **章节描述**：可选，一行摘要
5. **视觉分隔**：SVG 分隔线或间距
6. **装饰元素**：克制的强调形状
7. **页码标识**：**必需**

### 设计决策

1. **章节数量**：3 个用纵向列表；4-6 个用网格或紧凑版；7 个以上用多栏
2. **描述长度**：描述长时用纵向列表；无描述时用紧凑网格/卡片
3. **语气**：企业风用编号列表；创意风用卡片；学术风可用罗马数字
4. **一致性**：匹配封面页视觉风格

### 工作流

1. **分析**：章节列表、数量、演示上下文
2. **选择版式**：根据章节数量和内容选择
3. **规划视觉层级**：编号样式、字号、间距
4. **编写页面**：使用 PptxGenJS。用形状做装饰元素。**必须包含页码标识。**
5. **验证**：生成预览，用 markitdown 提取文本，确认内容和页码标识都存在。

## 3. 章节分隔页

- **适用**：在主要部分之间做清晰过渡
- **内容**：章节编号 + 标题（+ 可选 1-2 行引言）

### 版式选项

**强居中**：适合极简、现代演示
```
|                  02                    |
|              章节标题                  |
|            可选引言一行                |
```

**左对齐 + 强调色块**：适合企业、结构化演示
```
| ████ |  02                            |
| ████ |  章节标题                      |
| ████ |  可选引言一行                  |
```

**分割背景**：适合高对比、戏剧化转场
```
| ██████████ |     章节标题              |
| ██  02  ██ |     可选引言              |
| ██████████ |                          |
```

**全幅背景 + 覆盖层**：适合创意、大胆演示
```
| ████████████████████████████████████  |
| ████       大号 02        █████████   |
| ████       章节标题       █████████   |
| ████████████████████████████████████  |
```

### 字号层级

| 元素 | 推荐尺寸 | 说明 |
|---------|-----------------|-------|
| 章节编号 | 72-120px | 加粗、强调色或半透明 |
| 章节标题 | 36-48px | 加粗、清晰、主文本色 |
| 引言文字 | 16-20px | 轻字重、弱化色、可选 |

**关键原则：**
1. **戏剧化编号**：章节编号是最突出的视觉元素
2. **强标题**：标题足够大，但明显次于编号
3. **内容极简**：只放编号 + 标题 + 可选一句话
4. **留白充足**：分隔页是停顿时刻，要留出呼吸感

### 内容元素

1. **章节编号**：必需。格式为 `01`、`02`... 或 `I`、`II`...，与目录页一致
2. **章节标题**：必需，清楚、简洁
3. **引言文字**：可选，1-2 行描述
4. **装饰元素**：SVG 强调形状（色条、线、几何块）
5. **页码标识**：**必需**

### 设计决策

1. **语气**：企业风用强调色块；创意风用全幅背景；极简风用强居中
2. **颜色**：背景/强调使用强色板色；文本保持高对比
3. **一致性**：同一份演示中所有分隔页使用同一种风格
4. **与内容页对比**：视觉上应明显不同，如背景色不同、留白更多

### 工作流

1. **分析**：章节编号、标题、可选引言
2. **选择版式**：根据内容和语气选择
3. **编写页面**：使用 PptxGenJS。用形状做装饰元素。**必须包含页码标识。**
4. **验证**：生成预览，提取文本，确认内容和页码标识。

## 4. 内容页

根据内容选择子类型。每个内容页只属于一个子类型：

### 子类型

**文本**：项目符号、引用或短段落
- 仍然必须包含图标或 SVG 形状，不能只有纯文本
```
|  页面标题                            |
|  * 要点一                            |
|  * 要点二                            |
|  * 要点三                            |
```

**混合媒体**：双栏，或半幅图片 + 文本
```
|  页面标题                            |
|  文本内容        |  [图片/视觉]       |
|  和要点          |                    |
```

**数据可视化**：图表（SVG 条形/进度/环形）+ 结论
- 必须包含数据来源
```
|  页面标题                            |
|  [SVG 图表]      |  关键结论 1        |
|                  |  关键结论 2        |
|                  来源：xxx           |
```

**对比**：并排栏或卡片（A vs B、优缺点）
```
|  页面标题                            |
|  ┌─ 选项 A ─┐  ┌─ 选项 B ─┐        |
|  │  细节 1  │  │  细节 1  │        |
|  └──────────┘  └──────────┘        |
```

**时间线 / 流程**：带箭头的步骤、旅程、阶段
```
|  页面标题                            |
|  [1] ──→ [2] ──→ [3] ──→ [4]       |
|  步骤    步骤    步骤    步骤        |
```

**图片展示**：主视觉图片、图库、视觉优先版式
```
|  页面标题                            |
|  ┌────────────────────────────────┐ |
|  │           [主图]               │ |
|  └────────────────────────────────┘ |
|  图注或辅助文本                      |
```

### 字号层级

| 元素 | 推荐尺寸 | 说明 |
|---------|-----------------|-------|
| 页面标题 | 36-44px | 加粗，位于页面顶部 |
| 小节标题 | 20-24px | 加粗，用于页内小节 |
| 正文 | 14-16px | 常规字重，左对齐 |
| 图注 / 来源 | 10-12px | 弱化色，最小字号 |
| 统计强调 | 60-72px | 关键统计数字用大号加粗 |

**关键原则：**
1. **正文左对齐**：不要让段落或项目符号居中
2. **字号对比**：标题必须 36pt+，才能从 14-16pt 正文中凸显
3. **必须有视觉元素**：每个内容页至少有一个非文本元素
4. **留白**：边距至少 0.5"，内容块之间 0.3-0.5"

### 内容元素

1. **页面标题**：必需，位于页面顶部
2. **正文内容**：根据子类型放文本、要点、数据或对比内容
3. **视觉元素**：图片、图表、图标或 SVG 形状，始终必需
4. **来源 / 图注**：展示数据或外部内容时使用
5. **页码标识**：**必需**

### 设计决策

1. **子类型**：先确定子类型，它会驱动整个版式
2. **内容量**：内容密集时用多栏或较小字号；内容少时用更大元素和更多留白
3. **数据 vs 叙事**：数据密集用图表 + 统计强调；故事驱动用图片 + 引用
4. **变化**：每个内容页应与前一页使用不同版式
5. **一致性**：字体、颜色和间距必须与整份演示保持一致

### 工作流

1. **分析**：分析内容，确定子类型，规划版式
2. **选择版式**：选择最适合子类型和内容量的方案
3. **编写页面**：使用 PptxGenJS。用形状制作图表、装饰元素和图标。**必须包含页码标识。**
4. **验证**：生成 `slide-XX-preview.pptx` 预览。用 markitdown 提取文本，确认内容完整、无占位文本，并包含页码标识。

## 5. 总结 / 收尾页

- **适用**：总结 + 行动
- **内容**：关键结论、CTA/下一步、联系方式/二维码、致谢

### 版式选项

**关键结论**：适合教育、企业、数据驱动型演示
```
|  关键结论                            |
|  ✓  结论一                           |
|  ✓  结论二                           |
|  ✓  结论三                           |
```

**CTA / 下一步**：适合销售提案、方案建议、项目启动
```
|  下一步                              |
|  [1] 行动项一                        |
|  [2] 行动项二                        |
|  联系：email@example.com             |
```

**感谢 / 联系方式**：适合会议演讲、主题演讲
```
|              谢谢                    |
|         name@company.com             |
|         @handle | website.com        |
```

**分栏回顾**：适合同时需要总结和行动的演示
```
|  总结              |  下一步          |
|  * 要点一          |  联系我们：      |
|  * 要点二          |  email@co.com    |
|  * 要点三          |  [二维码]        |
```

### 字号层级

| 元素 | 推荐尺寸 | 说明 |
|---------|-----------------|-------|
| 收尾标题（“谢谢” / “总结”） | 48-72px | 加粗、有气势 |
| 结论 / 行动项 | 18-24px | 清楚、便于扫读 |
| 辅助文本 | 14-16px | 常规字重 |
| 联系方式 | 14-16px | 弱化色 |

**关键原则：**
1. **强收尾陈述**：主信息应最大、最突出
2. **条目易扫读**：结论/行动项简洁，每条一行
3. **联系方式清楚**：可读但不要压过主信息
4. **留下记忆点**：收尾自信、完整、精致

### 内容元素

1. **收尾标题**：必需
2. **结论要点**：3-5 条简洁总结（如适用）
3. **行动号召**：清晰下一步（如适用）
4. **联系方式**：邮箱、网站、社交账号（如提供）
5. **装饰元素**：用于保持视觉一致的 SVG 强调元素
6. **页码标识**：**必需**

### 设计决策

1. **收尾类型**：回顾、CTA、感谢，或组合
2. **内容量**：结论较多时用列表；简单收尾时用居中感谢
3. **受众行动**：需要受众行动时用 CTA；信息型演示用结论
4. **语气一致**：匹配封面页能量
5. **视觉区分**：特别，但不能和整份演示脱节

### 工作流

1. **分析**：收尾内容，包括结论、CTA、联系方式、感谢
2. **选择版式**：根据内容类型选择
3. **编写页面**：使用 PptxGenJS。用形状做装饰元素。**必须包含页码标识。**
4. **验证**：生成预览，提取文本，确认内容和页码标识。

## 额外版式模式

在内容页中使用这些模式，以增加视觉变化：

- **双栏**（左侧文本，右侧插图）
- **图标 + 文本行**（图标在彩色圆形中，加粗标题，下方描述）
- **2x2 或 2x3 网格**（一侧放图片，另一侧放内容块网格）
- **半幅出血图片**（左侧或右侧全高图片）叠加内容
- **大号统计强调**（60-72pt 大数字，下方小标签）
- **对比栏**（前后对比、优缺点）
- **时间线或流程**（编号步骤、箭头）
- **章节标题旁的小彩色圆形图标**
- **斜体强调文本**用于关键统计或标语
