## 快速决策引擎

当用户给出模糊需求时（如"帮我规划个新疆游""9月去新疆怎么安排"），无需多轮追问，直接按以下决策树生成行程框架，再询问是否需要调整：

```
输入：天数 + 月份（可选）
  │
  ├─ 3-5天 → 东疆探秘 / 伊犁精华 / 冬季滑雪
  ├─ 6-8天 → 伊犁河谷 / 南疆风情
  ├─ 8-12天 → 北疆环线（最主流推荐）
  ├─ 15-20天 → 全疆大环线
  │
输入：兴趣关键词
  ├─ "人文/历史/丝路" → 南疆风情 + 丝路文化专线
  ├─ "草原/花海/摄影" → 伊犁河谷 + 摄影专线
  ├─ "美食/吃" → 美食专线（乌市→喀什→伊宁）
  ├─ "徒步/户外" → 徒步专线（夏塔/喀纳斯三湾/乌孙古道）
  ├─ "亲子/带娃" → 东疆探秘 + 亲子专题调整
  ├─ "滑雪/冬季" → 冬季滑雪路线
  └─ "都想去" → 全疆大环线
  │
输入：预算
  ├─ "穷游/省钱" → 住县城+大巴+选精华景点
  ├─ "舒适" → 三星连锁+包车+全覆盖
  ├─ "豪华/不差钱" → 景区内住宿+越野包车+全覆盖
  │
输出框架模板（30秒生成）
  → 路线名称 + 天数 + 逐日城市流向 + 预估人均总价 + 最佳月份
  → 末尾询问"需要我展开每日详细行程吗？"
```

## 核心工作流

### 1. 需求收集

收到新疆旅游相关请求时，先确认以下关键信息（缺失项主动询问，不一次性全部追问）：

- **出行天数**：总共几天
- **出行时间**：哪个月/哪个季节
- **人数与类型**：几人出行，是否有老人/小孩（触发特殊人群模块）
- **预算偏好**：穷游/舒适/豪华
- **兴趣偏好**：自然风光/人文历史/美食体验/摄影打卡/自驾冒险/徒步户外
- **出发城市**：从哪里飞/自驾出发
- **交通偏好**（可选）：自驾/包车/公共交通/混合
- **摄影需求**（可选）：是否重点摄影打卡
- **出行人群**（可选）：亲子/老人/独行/情侣/团建

### 2. 路线设计

根据需求选择主线：

| 路线 | 天数 | 核心体验 | 适合人群 |
|------|------|----------|----------|
| 北疆环线 | 8-12天 | 喀纳斯、赛里木湖、那拉提、独库公路 | 首次入疆、自然风光爱好者 |
| 伊犁河谷 | 5-7天 | 那拉提、喀拉峻、薰衣草、夏塔 | 草原花海、摄影爱好者 |
| 南疆风情 | 6-8天 | 喀什老城、塔县、帕米尔高原、沙漠公路 | 人文历史、民族风情爱好者 |
| 东疆探秘 | 3-5天 | 吐鲁番、哈密、火焰山、库木塔格沙漠 | 短途、家庭亲子 |
| 全疆大环线 | 15-20天 | 北疆+南疆全覆盖 | 长假深度游 |
| 冬季滑雪 | 3-5天 | 阿勒泰将军山/可可托海/丝路度假区 | 冬季运动爱好者 |
| 丝路文化专线 | 10天 | 故城+石窟+老城+古道 | 历史文化深度爱好者 |
| 摄影专线 | 12天 | 全顶级机位串联 | 摄影爱好者 |
| 美食专线 | 8天 | 三大美食城市深度吃 | 美食爱好者 |
| 徒步专线 | 8天 | 夏塔+喀纳斯+乌孙古道入门段 | 户外徒步爱好者 |

### 3. 行程输出格式

每日行程按以下结构输出：

```
### Day X — 城市/区域名
- **上午**：景点名（游玩时长、门票、亮点）
- **下午**：景点名（游玩时长、门票、亮点）
- **晚上**：美食/夜市推荐
- **住宿**：推荐区域及价位区间（详见 accommodation.md）
- **交通**：当日交通方式与耗时
- **摄影**：当日最佳机位与光线时间（如有摄影需求）
- **贴士**：当日特别注意事项
```

|------|------|------|------|------|----------|
| 穷游 | 80-150 | 60-100 | 100-200 | 50-150 | 290-600 |
| 舒适 | 200-400 | 120-200 | 200-400 | 100-300 | 620-1300 |
| 豪华 | 500-1500 | 300-500 | 400-800 | 200-500 | 1400-3300 |

详细预算项见 `references/budget.md`。

## 核心提醒（每次输出行程时附带）

- **时差**：新疆与内地约2小时时差，作息建议延后2小时
- **防晒**：紫外线极强，SPF50+防晒霜+墨镜+遮阳帽必备
- **温差**：早晚温差15-25°C，即使夏天也带抓绒/薄羽绒
- **证件**：身份证随身带；去塔县/红其拉甫等边境地区需办边防证
- **独库公路**：仅6月中旬-10月中旬开放，仅限7座及以下车辆，逢站必加满油
- **安检**：各检查站需刷身份证，机场/车站提前1-1.5h到达
- **补水**：气候极干燥，日饮水量2L+，随身带润唇膏和护手霜
- **现金**：大部分地方支持移动支付，偏远山区/牧民建议带少量现金
- **信号**：山区/峡谷/独库公路部分路段无信号，提前下载离线地图
