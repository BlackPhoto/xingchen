## 住宿策略总则

| 原则 | 说明 |
|------|------|
| 旺季提前订 | 7-8月景区内住宿至少提前30天预订，禾木/喀纳斯提前45天 |
| 住县城不住景区 | 景区门口比景区内便宜50-70%，县城比景区门口再便宜30% |
| 包车师傅同住 | 部分客栈给司机免费房或低价房（50-80元），降低包车总成本 |
| 看评价不看星级 | 新疆部分"农家乐"比三星酒店体验好，看携程/去哪儿真实评价 |
| 带一次性用品 | 部分民宿/农家乐不提供牙刷毛巾，自带更卫生 |
| 确认有热水 | 偏远地区太阳能热水器晚上热水可能不够，洗澡要趁早 |

| 住宿点 | 距景区 | 价格（旺季） | 优势 |
|--------|--------|-------------|------|

## 住宿省钱技巧

1. **住县城不住景区**：喀纳斯住布尔津省50-70%，那拉提住新源省40-60%
2. **拼房分摊**：同性旅伴拼标间/家庭房，人均省一半
3. **住青旅**：乌鲁木齐/伊宁/喀什有国际青旅，50-80元/床位
4. **民宿砍价**：淡季直接电话民宿老板谈价，比平台低20-30%
5. **包车推荐住宿**：包车司机推荐的客栈有协议价，比携程便宜10-20%
6. **长住优惠**：同一客栈住3晚+可谈9折，5晚+可谈8折
7. **避开周末**：周五周六入住比周日到周四贵10-20%
8. **关注新店**：新开业的民宿冲评分期价格很低，条件未必差
9. **露营替代**：赛里木湖/那拉提/巴音布鲁克可自带帐篷（注意景区是否允许扎营）
10. **不选含早**：新疆早餐一碗拌面15元，酒店早餐多收30-50元不划算
