## 民族概况

新疆是中国少数民族自治区，共有47个民族世居。主要民族：

| 民族 | 人口比例 | 主要聚居区 | 主要信仰 |
|------|----------|------------|----------|
| 维吾尔族 | 约45% | 南疆（喀什/和田/阿克苏） | 伊斯兰教 |
| 汉族 | 约40% | 全疆城镇 | — |
| 哈萨克族 | 约7% | 北疆（伊犁/阿勒泰/塔城） | 伊斯兰教 |
| 回族 | 约4% | 全疆城镇 | 伊斯兰教 |
| 柯尔克孜族 | 约1% | 克孜勒苏 | 伊斯兰教 |
| 蒙古族 | 约1% | 巴音郭楞/博尔塔拉 | 藏传佛教 |
| 塔吉克族 | 约0.3% | 塔什库尔干 | 伊斯兰教（什叶派） |
| 锡伯族 | 约0.2% | 察布查尔 | — |
| 乌孜别克族/塔塔尔族/俄罗斯族/达斡尔族 | <0.1%各 | 散居 | 各异 |

## 维吾尔族文化与礼仪

### 基本礼仪

| 场景 | 礼仪 |
|------|------|
| 问候 | 男性间握手说"萨拉姆"（和平之意），握手后右手抚胸口 |
| 女性 | 不主动与男性握手，除非对方先伸手 |
| 称呼 | 尊称男性"阿卡"（哥哥），女性"阿恰"（姐姐），老人"达达"（爷爷）/"阿娜"（奶奶） |
| 进门 | 先迈右脚进门，进门后脱鞋 |
| 坐姿 | 盘腿坐在地毯上，不伸腿指向他人 |

### 家庭做客

1. **带礼物**：带水果/糕点/茶叶，不用带酒
2. **洗手**：进门后主人端壶倒水洗手，用毛巾擦干
3. **就座**：按主人引导入座，长辈坐上座
4. **茶饮**：主人倒茶双手接，小口饮，茶碗只剩底时主人会续杯
5. **馕**：掰开吃，不整个咬；掉地上的碎渣捡起来
6. **用餐**：用右手取食（手抓饭用右手三指），不用左手递东西
7. **夸赞**：夸孩子可爱/食物好吃，主人会很高兴

## 哈萨克族文化与礼仪

### 基本礼仪

| 场景 | 礼仪 |
|------|------|
| 问候 | 握手说"萨拉姆"，下马/下车先行礼再说话 |
| 进毡房 | 从左侧进入，右手掀门帘 |
| 就座 | 正对门为上座（长辈/贵宾），左侧女客，右侧男客 |
| 奶茶 | 主人倒茶双手接，喝完示意不想喝时手覆碗口 |

### 牧区做客

1. **不拒绝食物**：主人端来的奶茶/奶疙瘩/包尔萨克要品尝
2. **尊重马匹**：哈萨克族是马背民族，不对马匹粗鲁
3. **骑马**：从左侧上马，不拍马臀部
4. **冬不拉**：主人弹冬不拉时可鼓掌，不要打断
5. **礼物**：糖果/茶叶/小礼品给主人家孩子即可
6. **宰牲**：牧民可能宰羊招待贵客，不浪费食物是对主人的尊重

## 清真寺参观礼仪

### 基本规矩

| 项目 | 要求 |
|------|------|
| 着装 | 长裤长袖，女性需戴头巾（入口处可借） |
| 入内 | 脱鞋，从右脚迈入 |
| 行为 | 保持安静，不大声说话/嬉笑 |
| 拍照 | 礼拜时间禁止拍照，平时拍照前征得同意 |
| 性别 | 部分清真寺女游客限入，或女士有单独入口 |
| 古兰经 | 不触碰经书，不以脚指向经书/礼拜方向 |
| 礼拜 | 不从正在礼拜的人前面走过 |
| 清洁 | 保持寺内整洁，不带入食物/饮料 |

### 主要可参观清真寺

| 清真寺 | 城市 | 备注 |
|--------|------|------|
| 艾提尕尔清真寺 | 喀什 | 中国最大清真寺，非礼拜时间可参观 |
| 陕西大寺 | 乌鲁木齐 | 中式建筑风格清真寺 |
| 吐鲁番清真寺 | 吐鲁番 | 小型社区清真寺 |

## 做客与餐饮礼仪

### 用餐规矩

1. **右手优先**：递东西、取食物、握手均用右手
2. **不用左手**：左手在伊斯兰文化中被视为不洁
3. **不浪费**：盘里的食物尽量吃完，浪费被视为不尊重
4. **手抓饭**：用右手三指（拇指/食指/中指）捏取，送入口中
5. **吃馕**：掰开吃，不咬整个馕
6. **喝酒**：穆斯林家庭不主动提供酒，客人也不带酒/不在穆斯林面前饮酒
7. **饭前祈祷**：主人可能会说"穆斯坎达斯提"（以真主名义开始），安静等待即可
8. **饭后感恩**：饭后说"热合麦特"（谢谢），双手抚胸口

### 餐桌禁忌

- **不翻鱼**：吃鱼不翻面（象征翻船），吃完一面去掉鱼骨吃另一面
- **不掉馕渣**：掉在地上要捡起来，馕是神圣食物
- **不吹食物**：热食不吹气，等凉了再吃
- **不敲碗**：敲碗被视为乞讨行为

## 巴扎文化

### 赶巴扎须知

| 项目 | 说明 |
|------|------|
| 时间 | 喀什大巴扎每天开放，农村巴扎按星期轮换（每周一次） |
| 讲价 | 大巴扎可以讲价，从对方报价的5-6折开始还 |
| 现金 | 部分摊位不支持移动支付，备少量现金 |
| 试吃 | 干果/糕点可以先尝后买，不限购 |
| 礼貌 | 不买的东西不乱动，看完放下说"热合麦特"（谢谢） |
| 合影 | 与摊主/巴扎人物拍照前征得同意 |
| 假货 | 玉石/药材/香料注意鉴别，不懂不买 |

### 特色巴扎推荐

| 巴扎 | 位置 | 特色 |
|------|------|------|
| 喀什国际大巴扎 | 喀什市区 | 中亚最大集市之一，民族 goods 最全 |
| 国际大巴扎 | 乌鲁木齐 | 旅游纪念品+美食，游客友好 |
| 牛羊巴扎 | 喀什荒地乡 | 每周日，活畜交易，人文摄影胜地 |
| 干果巴扎 | 吐鲁番/和田 | 葡萄干/红枣/巴旦木产地直供 |

## 摄影与肖像礼仪

### 基本原则

1. **先问后拍**：拍人脸前先用 gestures 或语言征得同意
2. **尊重拒绝**：对方摇头/摆手表示不愿被拍，立即收手
3. **不给钱拍照**：养成"拍照给钱"的习惯会破坏当地文化生态
4. **清真寺内**：礼拜时间不拍，平时问阿訇/管理人员可否拍
5. **老人与孩子**：拍老人前尤其要征求同意；拍孩子时先问家长
6. **赶集/巴扎**：拍商贩前先买点东西或打个招呼
7. **女性**：对穆斯林女性拍照要格外注意，部分女性不愿被陌生男性拍
8. **军事设施**：任何军事设施/检查站/边防哨所不拍

### 实用话术

| 场景 | 维吾尔语 | 意思 |
|------|----------|------|
| 请求拍照 | "Rasimge chüshse bolidu?" | 可以拍照吗？ |
| 征得同意后 | "Rahmat" | 谢谢 |
| 对方拒绝 | "Bolidu, rahmat" | 没关系，谢谢 |
| 夸赞 | "Chong guzel" | 太美了 |
| 打招呼 | "Yaxshimusiz" | 你好 |

> 简单学几句维语/哈语，当地人会格外热情。最实用的是"热合麦特"（谢谢）和"亚克西"（好）。

## 禁忌一览

### 宗教类禁忌

| 禁忌 | 说明 |
|------|------|
| 猪肉 | 不在穆斯林面前提"猪"字/吃猪肉制品 |
| 酒 | 不在穆斯林面前饮酒/送酒 |
| 古兰经 | 不以脏手触碰，不放在地上，不以脚指向 |
| 礼拜 | 不在礼拜时间打扰/大声喧哗/从中穿行 |
| 清真标志 | 不质疑/嘲笑"清真"概念 |

### 生活类禁忌

| 禁忌 | 说明 |
|------|------|
| 左手递物 | 不用左手递/接东西，用右手或双手 |
| 鞋底朝人 | 坐着时不把鞋底朝向他人 |
| 头部 | 不摸他人头部（即使是孩子） |
| 馕 | 不把馕扔在地上/当坐垫/踩踏 |
| 数字13 | 部分民族忌讳13（受俄罗斯族影响） |
| 吹口哨 | 哈萨克族认为夜间吹口哨招不吉 |

### 政治类禁忌

- **不议论宗教政策**：避免讨论宗教管理、去极端化等敏感话题
- **不议论民族政策**：避免评价民族自治制度
- **不拍摄军事/警务设施**：检查站、边防哨所、警务亭绝不可拍
- **不携带违禁品**：不携带管制刀具/易燃品/政治宣传品

## 文明旅游须知

1. **垃圾不落地**：草原/沙漠/公路沿途带走自己的垃圾
2. **爱护环境**：不攀折花木/不踩踏农田/不在景区刻字
3. **尊重排队**：景区/区间车/检查站排队不插队
4. **控制音量**：清真寺/博物馆/民居不大声喧哗
5. **节约用水**：新疆水资源极其珍贵，洗澡用水控制
6. **减速让行**：自驾遇到牧民赶牛羊/马群停车让行
7. **不喂野生动物**：赛里木湖天鹅/草原旱獭不投喂人类食物
8. **保护文物**：故城/石窟/壁画不触摸不刻字
9. **入乡随俗**：尊重当地作息时间（新疆时间比内地晚约2h）
10. **理性消费**：不贪图便宜买问题玉石/药材，不懂不买
