## 无人机航拍指南

### 禁飞区

| 区域 | 状态 |
|------|------|
| 机场周边8km | 严格禁飞 |
| 军事管理区（边境线5km内） | 严格禁飞 |
| 喀纳斯景区 | 需报备景区管理方 |
| 喀什老城 | 可飞但注意人流 |
| 独库公路 | 可飞，注意信号 |
| 塔县/红其拉甫方向 | 边境禁飞区，严禁起飞 |

### 航拍推荐机位

| 地点 | 高度建议 | 注意事项 |
|------|----------|----------|
| 盘龙古道 | 100-200m | 俯拍600+弯道最震撼 |
| 禾木村 | 50-100m | 日出时炊烟+晨雾 |
| 赛里木湖 | 50-150m | 环湖俯拍湖岸线 |
| 世界魔鬼城 | 50-100m | 雅丹地貌俯瞰 |
| 琼库什台 | 100-200m | 松林+草原+河谷 |
| 天山神秘大峡谷 | 50-80m | 峡谷走势俯瞰 |

### 注意事项
- 高原/高海拔地区电池续航下降30-40%，多带备用电池
- 山区风速大，风速>8m/s不建议起飞
- 沙漠地区注意沙尘损坏电机，飞行后及时清洁
- 边境地区务必确认是否禁飞，违规可能被没收设备

## 手机摄影技巧

1. **善用超广角**：拍草原/湖面/峡谷全景时切0.5x，增加画面张力
2. **低角度构图**：拍花海/草原时手机贴地，前景花朵放大画面层次
3. **逆光剪影**：日落时拍人物/骆驼/毡房剪影，曝光减1-2档
4. **对称倒影**：赛里木湖/卡拉库里湖无风时拍对称倒影
5. **人像模式**：拍人文肖像虚化背景，突出人物表情
6. **全景模式**：峡谷/公路/草原用全景横扫，替代超广角
7. **延时摄影**：云朵流动/日出/日落/星空用手机延时功能
8. **HDR模式**：大光比场景（雪山+暗部山谷）开启HDR保留细节
9. **网格线辅助**：开启三分线构图，地平线放在上下1/3处
10. **后期APP**：Snapseed调色、Lightroom修RAW、VSCO滤镜

## 星空与银河拍摄

### 最佳条件

| 条件 | 要求 |
|------|------|
| 时间 | 7-8月无月夜（农历初一前后5天） |
| 地点 | 喀纳斯湖边、赛里木湖、禾木村、琼库什台 |
| 光污染 | 远离城市30km以上 |
| 天气 | 晴朗无云，风力<3级 |

### 拍摄参数

| 器材 | 参数 |
|------|------|
| 相机 | M档，手动对焦无限远 |
| 光圈 | f/2.8或更大 |
| 快门 | 15-25秒（500法则：500/焦距=最长曝光秒数） |
| ISO | 3200-6400 |
| 三脚架 | 必须 |
| 快门线 | 推荐，避免按快门抖动 |

### 银河构图技巧
- 找北极星确定银河方向（7-8月银河核心朝南偏西）
- 地景+银河：木屋/毡房/蒙古包做前景，银河做背景
- 人像+银河：人物打微弱补光（手机屏幕光即可），长曝光拍摄
- 延时星空：每张间隔1-3秒，拍200-300张合成延时视频
