## 证件与安检

### 必带证件

| 证件 | 用途 | 备注 |
|------|------|------|
| 身份证 | 全程必须 | 检查站/酒店/景区/加油站均需刷证 |
| 边防证 | 边境地区 | 塔县/红其拉甫/部分阿勒泰地区需要 |
| 驾照 | 自驾 | 内地C照即可，港澳台需翻译公证 |
| 学生证 | 景区优惠 | 部分景区半价 |
| 老年证 | 景区优惠 | 65岁以上多数景区免票/半价 |
| 军人证/残疾证 | 景区优惠 | 多数景区免票 |

### 安检须知

| 场景 | 要求 |
|------|------|
| 机场 | 提前1.5h到达，托运液体>100ml |
| 火车站/高铁 | 提前1h到达，安检排队较长 |
| 检查站 | 全员下车刷身份证+刷脸，摇下车窗配合检查 |
| 景区 | 包过安检机，打火机/刀具可能被收 |
| 酒店 | 每人刷身份证登记，离境/离店再次核验 |
| 加油站 | 司机刷身份证+刷脸，同车人员站外等候 |

### 重要提醒
- **身份证随身带**：不要放在行李箱里，安检/检查站需要随时出示
- **身份证消磁**：消磁后无法刷证，提前检查或带社保卡备用
- **丢失身份证**：到当地派出所开临时身份证明

## 边防证办理

### 需要边防证的地区

| 地区 | 涵盖范围 | 备注 |
|------|----------|------|
| 塔什库尔干县 | 塔县全境、卡拉库里湖、红其拉甫 | 最常去 |
| 阿勒泰部分区域 | 喀纳斯部分区域、白哈巴 | 白哈巴必需 |
| 哈密部分区域 | 巴里坤边境 | 较少涉及 |
| 克孜勒苏部分区域 | 乌恰县、阿合奇县 | 较少涉及 |
| 和田部分区域 | 民丰县等 | 较少涉及 |

### 办理方式

| 方式 | 地点 | 耗时 | 适合 |
|------|------|------|------|
| 户籍地办理 | 当地公安局/派出所 | 当天-3天 | 最推荐，提前办好 |
| 喀什市办理 | 喀什市行政服务中心/派出所 | 1-2h | 到喀什后补办 |
| 塔县办理 | 塔县城关派出所 | 30min-1h | 到塔县入口办 |

### 办理所需材料
- 身份证原件
- 2张1寸免冠照片（部分地方现场拍照）
- 填写《边境管理区通行证申请表》
- 免费

### 提示
- **提前在家办最稳妥**：带上户籍地开的边防证，到新疆直接用
- **喀什市办证很快**：喀什市色满路/行政服务中心，1-2h出证
- **写明目的地**：办理时写清楚要去的地方（如"塔什库尔干县"）
- **有效期**：一般为3个月，在有效期内反复使用

## 高反预防与处理

### 新疆高海拔区域

| 地点 | 海拔 | 高反风险 |
|------|------|----------|
| 塔县 | 3100m | 轻度 |
| 卡拉库里湖 | 3600m | 中度 |
| 红其拉甫口岸 | 4700m | 高度 |
| 独库公路哈希勒根达坂 | 3400m | 轻度 |
| 盘龙古道 | 4200m | 中度 |
| 巴音布鲁克 | 2500m | 极低-轻度 |
| 天山天池 | 1900m | 几乎无 |

### 高反症状

| 级别 | 症状 | 处理 |
|------|------|------|
| 轻度 | 头痛、失眠、食欲下降 | 休息、喝水、不剧烈运动 |
| 中度 | 剧烈头痛、恶心呕吐、呼吸困难 | 吸氧、下降海拔500m+ |
| 重度 | 意识模糊、严重呼吸困难、不能行走 | 立即下降海拔+就医 |

### 预防措施

1. **循序渐进**：从喀什（1300m）到塔县（3100m）有一天的车程适应
2. **不剧烈运动**：到达高海拔当天不跑跳、不搬重物
3. **多喝水**：日饮2-3L水，保持尿液淡黄
4. **不饮酒**：到达高海拔当晚不喝酒
5. **充足睡眠**：第一晚早睡，不熬夜
6. **饮食清淡**：少吃油腻，多吃碳水化合物
7. **备药**：
   - 红景天（提前3-5天开始吃）
   - 葡萄糖口服液
   - 布洛芬（缓解头痛）
   - 速效救心丸（心脏不适时舌下含服）

### 高反应急处理
- **立刻吸氧**：塔县/喀什药店有售便携氧气罐（30-60元/罐）
- **下降海拔**：最有效的办法，从塔县返回喀什（海拔下降1800m）
- **保持冷静**：轻度高反很常见，紧张会加重症状
- **及时就医**：重度症状不缓解必须就医或拨打120

### 防晒（夏季重点）

| 措施 | 说明 |
|------|------|
| 防晒霜 | SPF50+ PA++++，每2h补涂，面部+颈部+手臂 |
| 墨镜 | UV400防护，偏光镜更佳 |
| 遮阳帽 | 宽檐帽遮住脸+脖子，草原选有防风绳的 |
| 防晒衣 | UPF50+，轻薄透气面料 |
| 面巾/围脖 | 沙漠/戈壁防风沙+防晒 |
| 唇膏 | SPF15+防晒润唇膏 |

### 防寒（夜间/高海拔/冬季）

| 场景 | 温度范围 | 建议穿着 |
|------|----------|----------|
| 喀纳斯9月日出 | -2~5°C | 薄羽绒+抓绒+帽子手套 |
| 独库公路达坂 | 5~10°C（风大体感更低） | 冲锋衣+抓绒 |
| 塔县夜间 | 0~5°C | 抓绒+薄羽绒 |
| 冬季阿勒泰 | -25~-10°C | 厚羽绒+保暖内衣+雪地靴 |

> **核心原则**：洋葱穿衣法——多层薄衣叠加，热了脱冷了穿，随时调节。

## 饮食安全

### 常见问题

| 问题 | 原因 | 预防 |
|------|------|------|
| 肠胃不适 | 烤肉/手抓饭油腻辛辣 | 备蒙脱石散/藿香正气水，不暴食 |
| 上火 | 烤制食物多、气候干燥 | 多喝水/茶，吃水果，备牛黄解毒片 |
| 拉肚子 | 路边摊/生冷食物 | 选择卫生条件好的餐馆，少吃凉拌菜 |
| 缺维生素 | 蔬菜摄入少 | 带复合维生素片，在城镇点蔬菜 |

### 饮食安全要点

1. **选择餐馆**：优选有营业执照的正规餐馆，看大众点评评分
2. **烤肉**：确保肉完全烤熟，不贪图嫩度吃半生肉
3. **水果**：买回来的水果洗净去皮再吃
4. **水源**：喝瓶装水或烧开的自来水，不喝生水
5. **奶制品**：奶疙瘩/酸奶从正规渠道买，散装注意日期
6. **夜市**：夜市选择人多、流转快的摊位（食材新鲜）
7. **过敏**：对坚果/蜂蜜/羊肉过敏者随身带抗过敏药

## 交通安全

### 自驾安全

| 风险 | 预防 |
|------|------|
| 疲劳驾驶 | 每2h休息15min，换驾，不赶夜路 |
| 山路弯道 | 进弯前减速鸣笛，不越线 |
| 牲畜上路 | 注意牛羊/马群横穿公路，减速避让 |
| 沙尘暴 | 能见度低时停车开双闪，等风沙过去 |
| 大雪封路 | 关注独库公路公众号，不强行通过 |
| 冰路 | 冬季带防滑链，减速慢行不急刹 |
| 路边停车 | 不在弯道/坡道/窄桥停车拍照 |

### 乘车安全
- **系安全带**：全程系安全带（含后排），检查站会查
- **不超速**：新疆测速严格，区间测速+固定测速+移动测速
- **不酒驾**：饮酒后不开车（景区/检查站可能抽查）
- **应急工具**：备胎+千斤顶+三角架+灭火器+反光背心

## 沙漠与山区安全

### 沙漠安全

| 风险 | 预防 |
|------|------|
| 迷路 | 不独自深入沙漠，跟景区路线走，带GPS |
| 中暑 | 避开正午高温，戴帽遮阳，日饮3L+水 |
| 沙尘暴 | 沙尘暴来时面朝背风方向蹲下，用围巾遮口鼻 |
| 车辆陷入 | 沙地行车降低胎压+挂低速四驱，备拖车板+拖车绳 |
| 防沙 | 相机/手机密封袋保护，镜头用UV镜+吹球清洁 |

### 山区安全

| 风险 | 预防 |
|------|------|
| 山洪 | 天山神秘大峡谷/峡谷类景区下雨天不入内 |
| 落石 | 注意观察上方岩壁，不在松散碎石下停留 |
| 迷路 | 徒步跟栈道走，不走野路，下载离线地图 |
| 扭伤 | 穿防滑徒步鞋，走不平路面用登山杖 |
| 气温骤降 | 山中天气多变，随身带一件保暖层 |

## 旅游保险建议

### 推荐保险类型

| 类型 | 保额建议 | 费用参考 | 保障范围 |
|------|----------|----------|----------|
| 意外身故/伤残 | 50-100万 | 含在旅游险中 | 意外事故 |
| 意外医疗 | 5-10万 | 含在旅游险中 | 意外受伤医疗费 |
| 紧急医疗救援 | 50-100万 | 含在旅游险中 | 高原/偏远地区转运 |
| 高原反应 | 需确认条款 | 部分险种不含 | 高反医疗费 |
| 自驾意外 | 50万 | 车险+人身意外险 | 自驾事故 |
| 行程延误/取消 | 实报实销 | 含在旅游险中 | 航班取消/天气原因 |
| 个人责任 | 10-50万 | 含在旅游险中 | 意外造成他人损失 |

### 购买建议
1. **选择含高原反应保障的保险**：去塔县/独库公路前确认条款
2. **含紧急医疗救援**：新疆地域辽阔，转运费可能上万元
3. **自驾额外买车上人员险**：交强险不含本车人员
4. **提前购买**：出发前购买生效，行程中买可能不覆盖已发生事故
5. **保单截图留存**：手机存电子保单+客服电话，离线可查
6. **推荐平台**：支付宝/微信/携程/慧择网，比较条款后选择
